# Laboratórios de Deep Learning

Coleção de cinco notebooks desenvolvidos durante meus estudos de **Inteligência Artificial e Ciência de Dados**. A sequência parte dos fundamentos matemáticos, constrói o perceptron e redes multicamadas, explora backpropagation e termina com técnicas de regularização.

## Trilha de aprendizagem

| Lab | Tema | Principais conceitos |
| --- | --- | --- |
| [01](notebooks/lab-01-fundamentos-matematicos.ipynb) | Fundamentos matemáticos | Vetores, matrizes, derivadas e operações usadas em redes neurais |
| [02](notebooks/lab-02-perceptron.ipynb) | Neurônio artificial e perceptron | Função de ativação, treinamento e implementação orientada a objetos |
| [03](notebooks/lab-03-mlp-feedforward.ipynb) | MLP e feedforward | Camadas densas, propagação direta e classificação com PyTorch |
| [04](notebooks/lab-04-backpropagation-otimizacao.ipynb) | Backpropagation e otimização | Gradientes, descida do gradiente e comparação de otimizadores |
| [05](notebooks/lab-05-regularizacao-overfitting.ipynb) | Regularização | Overfitting, dropout e estratégias de generalização |

## Tecnologias

**Python · Jupyter/Google Colab · NumPy · Matplotlib · scikit-learn · PyTorch · TensorFlow**

## Como executar

1. Use Python 3.10 ou mais recente.
2. Crie e ative um ambiente virtual.
3. Instale as dependências com: **pip install -r requirements.txt**
4. Inicie com: **jupyter lab**
5. Abra os notebooks na ordem numérica. O Lab 03 pode usar GPU quando disponível, mas também executa em CPU.

Os notebooks preservam as saídas da última execução para facilitar a leitura no GitHub. Execute todas as células novamente para reproduzir os resultados no seu ambiente.
